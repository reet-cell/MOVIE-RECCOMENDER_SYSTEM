# Movie Recommender System

## Overview

A content-based movie recommendation system that suggests similar movies based on genres, cast, crew, keywords, and movie descriptions.

## Features

* Content-based recommendation engine
* Movie metadata processing
* Cosine Similarity-based recommendations
* TMDB API integration for movie posters
* Interactive Streamlit interface

## Tech Stack

* Python
* Pandas
* Scikit-learn
* Streamlit
* TMDB API

## Project Workflow

1. Data Collection
2. Feature Extraction
3. Text Vectorization using CountVectorizer
4. Similarity Computation
5. Recommendation Generation

## Future Improvements

* Hybrid recommendation system
* Collaborative filtering
* Personalized user profiles
